# 微信桌面助手（Mac 原型）

这是一个面向普通微信桌面客户端的**本地优先原型**。目标是在专用助手账号已加入的群里读取指定会话、生成候选回复、让操作者随时暂停或接手，并明确记录每次发送尝试的结果。当前仓库不是可安装的自动回复产品，也没有持续监听、已接入的模型服务或客户群验收。

## 当前做到哪里

| 状态 | 已有证据或计划 |
| --- | --- |
| 已在隔离测试中观察到 | Mac 微信指定测试群的三条合成消息曾通过限定窗口截图与本地 Apple Vision OCR 读取；当前对话模型曾理解消息并生成测试回复；PyObjC/AppKit/辅助功能用于核窗口状态，Quartz 用于受控输入与点击。截屏空帧时会停止。 |
| 发送实测的边界 | 一次已编号的界面发送出现红色失败标志，另一测试身份确认未收到；另一次输入调用后失去截图，草稿是否存在未知，未点击发送。2026-10-07 用户另报告有一次成功发送，但未给出可归属到上述编号的送达证据，不能据此改写它们的结果。 |
| 仓库现有离线代码 | 账号限定的 outbox 状态库与合成模拟器已实现；当前离线单元测试在 Python 3.11 和 3.12 均为 13/13 通过。真实桌面执行器、适配器、监听器、模型接入和操作员界面尚未实现。 |
| 尚未证明 | 稳定读取、服务器消息 ID 或发送回执、任意真实消息去重、断线恢复、持续运行及客户同群场景。 |

当前方法通过桌面界面工作，**不是微信消息 API**。它依赖登录在这台 Mac 上的微信号发言。要让用户与助手在同一群中显示为两个成员，需要单独的助手账号；人工接手也必须围绕这个账号和同一个会话设计。

## 设计方向

推荐先做本地 Python + PyObjC 原生桌面适配器。每个账号只有一个串行 UI 执行者；读取优先使用客户端实际暴露的辅助功能元素，缺失时才在精确窗口和标题门禁下截取聊天区域交给本地 OCR。无像素、群标题不符、窗口变化、草稿未知或发送结果未知时停止自动动作。业务规则、上下文和模型适配器保持独立；目前没有选定模型供应商，也不配置对外模型调用。

现有 SQLite outbox 持久记录调用方提交的观察与发送尝试，只校验其目标绑定、新鲜度和状态顺序；它**不会自己读取前台应用、账号、屏幕锁或微信画面**。真实桌面驱动将来必须提供这些已核实的观察。界面点击、群内气泡、另一端确认是不同等级的结果；没有服务器回执时不承诺严格“恰好一次”发送。详情见[文档入口](docs/index.html)、[架构](docs/architecture.md)、[阶段计划](docs/plan.md)、[证据与状态](docs/status.md)及[安全边界](SECURITY.md)。

[现有试验机制图](.archify/architecture-current-mechanism-20261007-144533/current-mechanism.html)展示此前 Mac 试验实际使用的部件与边界；[目标系统概念图](.archify/architecture-target-system-20261007-144533/target-system.html)展示拟建设计。这两幅图不表示本仓库已具备完整桌面驱动、AI 服务或操作员界面。两图已通过 Archify 四项门禁并完成指定截图的人工查看；[图源与校验说明](docs/diagrams.md)区分了本地审阅和 CI 的静态一致性检查。

企业微信[智能机器人长连接接口](https://developer.work.weixin.qq.com/document/path/101463)是可研究的另一条路线：官方文档涉及群内 `@` 回调和已知 `chatid` 推送，但**含普通微信外部客户的群是否可用尚未获官方明确确认**。这条可选适配器不会在未核适用范围前写成已支持。

## 来源与许可边界

本仓库使用 [MIT 许可证](LICENSE)。

此前只读审查过 [dustin573/wechat-mcp 固定提交 `c6c600a`](https://github.com/dustin573/wechat-mcp/tree/c6c600ae068c113224f984656db40f8cec4d0164)：8 个 Python 源文件及项目文件，仓库标为 MIT。静态审查未见自有源码主动外传聊天或窃取凭据的证据；第三方依赖**没有逐行代码审查**。本仓库的新实现与该上游项目应分别判断，不把上游许可证或审查结论自动延伸到未来代码。

Apple 已将旧截图 API 列为弃用并推荐 [ScreenCaptureKit](https://developer.apple.com/documentation/macOS-Release-Notes/macos-15-release-notes)；[辅助功能接口](https://developer.apple.com/documentation/applicationservices/axuielement_h)能读取客户端愿意暴露的元素，[Vision OCR](https://developer.apple.com/documentation/vision/recognizing-text-in-images)则从图像识字。这三种能力不能互相替代，也不能单独保证微信版本兼容。

公开仓库只保留抽象设计、合成测试和脱敏结论，不包含聊天截图、账号或群名、消息原文、凭据及本机私有路径。实际试验资料留在被忽略的本地目录。
