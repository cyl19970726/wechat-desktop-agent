# 阶段计划与验收

本计划描述未来工作，不把离线检查写成桌面收发已通过。阶段可以分批完成，但进入客户群前必须满足与该范围对应的真实验证。

| 阶段 | 交付 | 通过条件 | 目前 |
| --- | --- | --- | --- |
| P0 公开基线 | 源码、威胁与数据边界、脱敏证据和可复建文档 | 公开检查不含截图、账号、凭据、原始消息或本机私有路径；链接和离线检查可重跑 | 内容已完成并在本地校验；公开状态以仓库实际状态为准，不等同客户试点验收 |
| P1 离线核心 | outbox 状态机、串行账号任务接口、合成事件模拟 | 重启、重复输入、发送结果未知、暂停/恢复和并发竞争的测试通过；无真实微信依赖 | 已实现离线原型和合成模拟器，13 项测试通过；持续按验收条目扩充 |
| P2 本机只读适配 | 精确窗口绑定、AX/OCR 读取、截图健康熔断 | 只读指定测试会话；标题与窗口变化、空帧、错误来向均拒绝；不读取旁边会话 | 先前试验部分通过，尚不稳定 |
| P3 受控发送 | 单账号 UI owner、草稿门禁、输入复核、一次点击与结果记录 | 三个不同合成请求按期望处理；失败与未知不自动重发；另一测试身份确认至少一条送达 | 未通过。旧历史成功不替代新三轮验收 |
| P4 操作员与模型 | 暂停/接手界面、可替换模型适配器及最小数据传递；业务工具只调用权威平台后端 | 人能在发送前后接手；模型提供方与数据边界明确；模型不能越过后端权限或直接写预约数据；断线后状态可审查 | 未实现 |
| P5 客户试点 | 账号、群、运行环境及故障处理 | 只在已授权范围验证客户同群、账号身份、日常稳定性与人工接管；明确可回退 | 未开始 |

当前对话模型能解释合成测试问题，不代表 P4 的服务已安装、常驻或接入任何供应商。早期 Mac 试验中，读取过指定群三条合成消息，并曾产生成功发送的用户报告；另有明确失败和未知的尝试。详见[证据与状态](status.md)，不得把这些结果合并成“三轮闭环通过”。

每个阶段都保留失败路径：截图不可用、客户端 UI 更新、账号切换、模态窗口、非空或未知草稿、输出气泡无法确认、收件端未收到。运行时遇到这些情况应暂停并让操作者判断，而不是猜坐标或重复点击。
