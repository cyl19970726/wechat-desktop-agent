推荐的技术组合

原文复制 / 局部 OCR→分页与确认日志→CLI / 现有 Agent→一次发送与结果记录

优先取得微信复制的原文，视觉核对群、方向与选取范围；缺失时才使用限定聊天区域的 OCR。视觉观察不提供官方消息 ID，点击和自己的气泡也不等于对方收到。发送结果未知时保留状态，不自动重发。

原生 read/page 当前只返回单屏 OCR 行，方向未知；会话日志模块接收已核验气泡，尚未连到自动采集与 CLI；parse-copy 仅解析调用者提供的文字，明确不核实来源或历史完整性。Computer Use 试跑与仓库原生驱动是两条独立证据，不能互相替代。副屏与主屏仍共享键鼠和前台焦点。

01

恢复持续观察

核同一测试窗口在静止、聚焦和滚动后的有效画面。一次恢复不足以通过；当前只做标题诊断和受控重启。

02

读取并恢复上下文

自动框选复制原文，用至少三屏核条数、顺序、重复和长消息；确认重叠后追加本地记录，断档就停。

03

验证单次回复

核完整草稿与目标后只提交一次，回读失败标记并由另一身份确认收件。结果未知时不自动重发。
